# Abyss Curse Mod

[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

A tiny but configurable Minecraft mod that allows you to apply custom effects to the player for moving vertically.

## Description

The mod is inspred by "Made in Abyss" manga and anime series.

See full description on mod's curseforge page:
https://www.curseforge.com/minecraft/mc-mods/abyss-curse
